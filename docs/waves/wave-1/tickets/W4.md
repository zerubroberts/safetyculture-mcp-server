## GOAL
In `src/toolsets/schedules.ts` (export `schedulesTools`):
- `sc_list_schedules` (read, core): current Schedules API first; include legacy schedule items when present, and label each row's source. Rows id, title, template, recurrence in plain English when derivable, assignees, site, status (active/paused/ended), next due.
- `sc_get_schedule` (read). `sc_list_schedule_occurrences` (read): from `/scheduling/v1/feed/schedule_occurrences` with period and status filters (missed / late / completed / upcoming) and limit; rows schedule, due window, status, completed inspection id, assignee.
- `sc_pause_schedule`, `sc_resume_schedule` (write). `sc_end_schedule` (destructive).

In `src/toolsets/training.ts` (export `trainingTools`):
- `sc_list_courses`, `sc_get_course` (with lessons), `sc_list_training_paths`, `sc_get_course_progress` (per course or per user completion, from training analytics), `sc_training_leaderboard` (all read). `sc_assign_course` (write: update course assignments).

In `src/toolsets/headsup.ts` (export `headsupTools`):
- `sc_list_heads_ups` (read), `sc_get_heads_up` (read: message, completion counts, who has and has not completed, comments; untrusted).
