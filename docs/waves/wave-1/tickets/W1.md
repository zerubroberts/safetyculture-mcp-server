# TICKET W1: Inspections and templates toolsets

Repo: safetyculture-mcp, an open-source MCP server for Mitti (formerly SafetyCulture). Spec: docs/SPEC.md.

## FILES ALLOWED
src/toolsets/inspections.ts, src/toolsets/templates.ts, test/toolsets/inspections.test.ts, test/toolsets/templates.test.ts

## API SECTIONS
docs/api-index.md sections: Inspections, Templates, Response Sets, Media, and the inspections Data Feed. Run `node scripts/api-ref.mjs <slug>` for every endpoint you call.

## GOAL
In `src/toolsets/inspections.ts` (export `inspectionsTools`):
- `sc_search_inspections` (read, core): filters template_ids, site_ids, period (state which date it filters on), completed (true/false/any), archived, owner_id; limit + page_token. Use the inspections Data Feed (`/feed/inspections`, slug thepubservice_feedinspections, supports template/site/completed/archived/modified_after filters) or Search modified inspections. Rows: id, name, template, site, score_percentage, date completed, owner name, `link` (links.inspection) and `report_link` (links.report).
- `sc_get_inspection` (read, core): header details for one inspection (score, dates, owner, author, site, location, template, archived, duration).
- `sc_get_inspection_answers` (read, core, untrusted): flattened answers (section path, label, type, response text or selected options, failed flag, score, notes, media count) with `failed_only` and a max items limit. Repeated sections (dynamic fields) keep their grouping via parent id.
- `sc_get_inspection_report_link` (read, core): web report link + deep link endpoints.
- `sc_export_inspection_document` (read): start a PDF or Word export, poll until ready (bounded, max about 60 s), return the download URL and say it expires.
- `sc_list_inspection_media` (read), `sc_get_media_url` (read).
- Writes: `sc_start_inspection` (from template, optional site), `sc_update_inspection` (patch style: owner, site, and simple answer updates if supported), `sc_complete_inspection`, `sc_clone_inspection`, `sc_share_inspection`, `sc_restore_inspection`.
- Destructive: `sc_archive_inspection` (plan shows name/template/site), `sc_delete_inspection` (permanent).

In `src/toolsets/templates.ts` (export `templatesTools`):
- `sc_list_templates` (read, core): name search, include archived, limit/page_token.
- `sc_get_template` (read, core): metadata plus a compact question outline (section > label, type, response options) from the template definition; cap with a note.
- `sc_list_response_sets`, `sc_get_response_set` (read). `sc_restore_template` (write). `sc_archive_template` (destructive).
